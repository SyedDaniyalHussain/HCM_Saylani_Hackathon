# HCM Lite — Frontend Only

A responsive Human Capital Management demo built with React + Vite. It includes a dashboard, employees, attendance, leave requests, payroll, reports, announcements, settings, and a demo assistant.

## Requirements
- Node.js 18+ (Node.js 20 LTS recommended)
- npm

## Run locally
1. Extract the ZIP.
2. Open the extracted `hcm-lite-frontend` folder in VS Code.
3. Open Terminal in that folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Notes
- This is frontend-only; no backend or real AI API is connected.
- Demo data is stored in your browser's `localStorage`.
- Use `npm run build` to create a production build in `dist/`.
